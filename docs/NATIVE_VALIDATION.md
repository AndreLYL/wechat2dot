# 2.0.0a1 原生桥验收记录

2026-11-18，本地候选版。Mac 现有的官方模式继续提供服务；本次使用隔离数据库跑原生桥，真实账号只用于读取主房间。

| 验证范围 | 本次结果 |
| --- | --- |
| Mac、Linux 消息引擎 | 两个平台各运行 466 项，全部通过。包含 180 条来信超过旧版任务容量、跨页对账、流式消息、图片和转写、审批、真限流、过期补发和双向去重。 |
| 常驻进程 | 两端使用合成传输，在实际收信循环、SQLite 和发送循环之间验证一条微信来信入房间及一条 DOT 回复返回。 |
| 分段中断 | 合成微信传输在第二段发送期间终止真实子进程。重开数据库后，第一段保持已受理，第二段进入待核对，第三段继续发送。 |
| 升级和原型 | Mac 和 Linux 均通过数据库升级、备份还原和分段恢复检查。每个平台运行 29 项原型测试，28 项通过，跳过仅适用于 Windows 的控制台窗口测试。 |
| 安装交付物 | wheel 和源码包内容及许可证检查通过。wheel 在新环境中安装，Docker 镜像在本机构建；两者均能从正常命令入口返回候选版本和初装状态。 |
| 真房间 | 用原生对账组件读取已绑定账号所选主房间，首次读取 32 条，建立起点并再次对账。测试未启用微信发送端。 |
| Mac 自动保活 | 辅助功能助手在本机编译通过；定时、重试以及收到新上下文的确认用合成输入验证。 |
