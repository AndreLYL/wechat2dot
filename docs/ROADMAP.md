# 路线图

## Alpha：先让首位用户接通

- [x] 微信 / MCP / 持久队列核心。
- [x] wechat2dot CLI：初始化、扫码、凭据保存、分层离线诊断。
- [x] Windows、Linux、macOS 原生运行与共享行为测试。
- [x] 无账号演示与可选容器部署。
- [x] 项目自己的微信 ↔ 现有 DOT 真人文字验收（Windows 私人部署）。
- [x] 进度、图片识别与回传、CSV 文件处理与回传、微信转写输入及文字答复；见 [验收记录](VALIDATION.md)。
- [ ] DOT 外部应用工具、原音理解和生成语音答复的真人验收。
- [ ] Linux/macOS 真人接入验收；跨平台 CI 不替代真人验证。

## 第一批用户

- 安装耗时、失败阶段、恢复步骤和匿名成功率；不收集消息内容。
- 降低 Tunnel / 插件配置门槛，提供可核验的诊断指引。
- 任务状态与取消：先确认平台支持的控制接口，不把本地处理状态冒充平台任务状态。
- 以“微信发任务 → DOT 做研究 → 文件回传”的真实短演示作为项目首页证明。

## 传播目标：5,000 stars

这个目标没有自动增长保证。先完善可执行的安装与后台运行指引，再邀请少量具备权限的用户复现已完成的 Windows 真人验收；根据独立安装与持续使用反馈决定版本发布和推广。开源传播内容可以公开，用户自己的插件与 Tunnel 保持私有。
